Why This Architecture?
Random Forest

300 trees, class-balanced. Learns global activity patterns. Strong on cycling, running, lying.

K-Nearest Neighbors

7 neighbours, distance-weighted. Local density learner — complements RF on edge cases.

Soft Voting (RF×3, KNN×2)

Probability averaging gives more calibrated confidence than hard voting.

Temporal Smoothing

9-window confidence-weighted majority vote (4.5s context). +1.8pp over raw predictions.

PAMAP2 Sensor Reliability Checker
A machine learning system that classifies 11 physical activities from 3-location IMU sensors and determines whether each sensor is producing trustworthy readings.
01
Raw Sensors
100Hz IMU. 27 clean channels (acc, gyro, mag) across hand, chest, ankle.
02
Windowing
1s windows, 50% overlap. 85% purity filter removes transition noise.
03
264 Features
Time-domain stats, FFT, spectral entropy, cross-sensor correlation, tilt proxy.
04
Ensemble
RF + KNN soft-voting with class balancing. XGBoost validated separately.
05
Smoothing
9-window confidence-weighted temporal majority vote. +1.8pp accuracy.
06
Traffic Light
GREEN ≥75% · YELLOW 45–75% · RED <45% confidence thresholds.
Dataset
9 subjects · 11 activities · 2.7M sensor rows · 52,909 windows
Test: Subject 106 held out · LOSO avg 84.4% ± 8.8%
Key Engineering Choices
• Excluded heartRate (9Hz forward-filled — 91% duplicates)
• Excluded temp sensors (constant in 1s window)
• Cross-sensor correlation for standing vs ironing
• class_weight='balanced' for minority activities
